Tentang aplikasi

Rute Kampus ULBI

Aplikasi statis untuk GitHub Pages. Data bangunan dan jalur berasal dari GeoJSON kampus.

Rute dihitung di browser dengan graf polyline jalan. Garis penghubung pendek hanya menghubungkan titik bangunan ke jalur terdekat.
